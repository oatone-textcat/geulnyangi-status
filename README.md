# 팀 글냥이 번역 작업 현황판

GitHub Pages에 바로 올릴 수 있는 정적 사이트입니다.

## 파일

- `index.html` — 메인 페이지
- `styles.css` — 스타일

## GitHub Pages 배포

1. 새 저장소를 만들거나 기존 저장소에 두 파일을 업로드합니다.
2. GitHub 저장소의 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**를 선택합니다.
4. `main` 브랜치의 `/ (root)`를 지정하고 저장합니다.
5. 잠시 후 Pages 주소에서 사이트를 확인할 수 있습니다.

## 수정 포인트

- 프로젝트를 추가하거나 순서를 바꾸려면 `index.html`의 각 섹션을 수정하면 됩니다.
- 색상과 레이아웃은 `styles.css` 상단의 `:root` 변수에서 쉽게 조정할 수 있습니다.
- 현재 마지막 업데이트 표시는 `2026-09-28`로 설정되어 있습니다.
